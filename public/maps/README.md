# Bangladesh map boundary

`bangladesh-boundary.geojson` is the detailed on-screen Bangladesh ADM0 map mask used by the application. It was obtained from the [geoBoundaries](https://www.geoboundaries.org/) open boundary dataset (BGD ADM0).

The outline keeps OSM detail visible inside Bangladesh and hides all external tiles. It is a product display and coordinate-validation boundary only; it is not a legal boundary dataset.
